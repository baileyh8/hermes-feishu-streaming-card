# v5.0.27: Hermes v0.23.3 compatibility and intentional-silence card settlement

[中文](release-notes-v5.0.27.md)

This release adds compatibility for official Hermes v0.23.3 (`caafe5389ae585ef77387a962aee05b1bcf17029`) and fixes intentional-silence turns (such as background completion wakes returning `NO_REPLY`) leaking the marker onto Feishu cards and remaining stuck in progress.

- **Hermes v0.23.3 compatibility ([#537](https://github.com/baileyh8/hermes-feishu-streaming-card/issues/537) · [PR #538](https://github.com/baileyh8/hermes-feishu-streaming-card/pull/538))**: Register the `pm-0233` writer and launch family (including `hermes_scope.py` and `hermes_cli/main_resume_args.py`) with config schema 54, and adapt admission completion verification to `persistence_assembly.Persistence` and its `SQLiteAdmissionRepository` / `SQLiteSessionRuntimeRepository` interfaces (reading the persistent epoch from `current_epoch()` while instance identity comes from the in-process `SessionAuthority`) while verifying the underlying `SQLiteStore`, `StoreHolder`, scope, and file-replacement state. Unknown sources remain refused and managed files restore byte for byte.
- **Intentional-silence card settlement ([#535](https://github.com/baileyh8/hermes-feishu-streaming-card/issues/535))**: Hold potential silence-marker prefixes boundedly on `answer.delta`, emit `intentional_silence` only when Hermes permits silence, and settle the existing card in place while preserving any existing body, attachments, and approval receipts without sending completion notifications or recovery cards. Covers normal, queued-first (including empty `notification_no_reply`), and recursive queued follow-up silence verdicts and turn ownership; human turns where Hermes rejects silence use a dedicated `native_fallback` terminal disposition to retain native fallback delivery and keep duplicate/late terminal events idempotent.
- **CI gates**: Add pinned v0.23.3 source-binding, writer-family, and official-image (`preserved` / `cleared`) acceptance jobs.
- **Out of scope**: [#536](https://github.com/baileyh8/hermes-feishu-streaming-card/issues/536) (`~silent`) currently has screenshots only without version or log evidence and is not claimed resolved in this release.

Follow the [installation guide](../README-install.md) and retain existing manifests and backups. `doctor` reports source compatibility and installation state. The [GitHub Release](https://github.com/baileyh8/hermes-feishu-streaming-card/releases/tag/v5.0.27) records exact-commit CI, packaged installation, live Gateway/model, and Feishu client acceptance separately.
