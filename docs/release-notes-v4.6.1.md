# V4.6.1：Hermes 0.21.3 兼容与通知修复

- #326：工具回调 hook 选择必经赋值位置，避开 `mute_notification_reply` 的后置条件重置；普通对话恢复工具事件，静默对话仍保持静默。只有条件分支或嵌套函数中的未知布局不会被当作有效锚点。

- 正文思考按时间正序，工具面板继续最新优先；没有统计数据时不显示虚构的 Unknown/零值行，页脚不重复完成通知。
