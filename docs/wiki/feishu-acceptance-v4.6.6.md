## 已记录的候选证据（2026-09-21）

- 真实 Feishu API 接受隔离候选的独立审批回执 PATCH 与旧卡精简，原操作范围、问题和“允许一次”留在回执。macOS 飞书实际显示旧段仅保留原文/续答说明，完整回执在下，最终结果继续在更下方。
- 36 次模拟调用的真实卡片在正文与展开过程面板同时显示 #24、#25、#35、#36；桌面目视确认 #25 运行状态及 #24 前一步都可见。此项是展示夹具，不代表运行了 36 个真实工具。
- 真实平台同 scope 确认投递触发提前撤回；独立账本在隔离 sidecar 重启后恢复原计时，约 15.5 秒完成实际 DELETE。没有把恢复卡片导致的提前清理误记成到期计时。
- 本机 Hermes 当前源码的 10 个 native producer/Base delivery 方法签名与包装契约匹配；此项是源码契约证据，生产进程加载另验。

上述证据不替代升级后的真实 Gateway 首次按钮流程，也不代表手机已验收。发布/生产/回复门禁尚待最终记录。

PR #342 补充：真实回环 HTTP 在接受 POST 后断开响应、让卡片暂不可见，随后只读查询发现 pending 并取得实际 choice；断言只有一次 POST。另测单次慢查询受剩余预算约束、明确拒绝不查询。此项是传输故障夹具，不是对生产飞书链路主动断网。
