# v5.0.8 — PM installation and migration recovery

This release combines [#458](https://github.com/baileyh8/hermes-feishu-streaming-card/pull/458) and [#461](https://github.com/baileyh8/hermes-feishu-streaming-card/pull/461), and addresses the PM launcher/official-image report in [#462](https://github.com/baileyh8/hermes-feishu-streaming-card/issues/462). The [GitHub Release](https://github.com/baileyh8/hermes-feishu-streaming-card/releases/tag/v5.0.8) records publication and exact acceptance evidence.

- Store immutable wheels outside workspace members under content hashes. Bind the exact external path, digest and package resources; missing archive hashes may be read only from the already verified owned file URL. Retain older generation objects and reject symlinks, Windows junctions/reparse points and uninspectable state.
- Add explicit `integrity rebind-legacy`: read-only preview by default; `--yes` revalidates the same HOME, source/hooks/manifest/backups, observer records and ordinary wheel before rebinding. Preserve unrelated config and previous evidence. An owned older wheel must match its exact owner version and canonical entry point, with an ownership recheck; ordinary installation still requires the current version. Default install/restore stay strict. This supports verified POSIX PM decomposed installs only; Windows and old single-file installs refuse explicitly.
- Load the official CLI from the selected checkout, with exact main/init hashes and directory ancestry checks, so a PM workspace does not change the install key. `HERMES_INSTALL_ROOT` alone is insufficient.
- Add the exact v0.22.1 writer cohort and follow the verified install-identity bootstrap record to decide whether to migrate the private copy and plan the exact writer schema stamp while retaining all other semantic checks and complete postimage-byte comparison. Family labels are not one-to-one version labels.
- Distinguish the selected interpreter sysconfig library roots from Hermes source when the official v0.22.5 image embeds Python under the source tree. Unknown project modules and unsafe paths remain refused. Public diagnostics use fixed categories without raw private stderr/config/source URLs.

Stop the corresponding Gateway/sidecar and updater before recovery. Keep marker, manifest, preimage and journal evidence. See [PM recovery](wiki/pm-recovery.md). Changing the install source may create a new generation before observer admission: use verified explicit rebind, controlled restore, then fresh install where necessary. Same-wheel reinstall evidence does not establish arbitrary old-version upgrade compatibility. The independent manual-review fence is not cleared by rebinding and retains its identity/CAS and stopped-sidecar checks.

Archives retain versioned roots: enter `hermes-feishu-card-v5.0.8-<platform>/` after extraction. Historical assets and tags remain intact.

Local reproductions, ordinary-wheel/actual-PM checks, digest-pinned official images and exact CI are recorded separately. Candidate/merge/tag matrices, CodeQL, anonymous downloads, checksums, complete archive contents and actual extraction are verified before publication and linked from Release. Missing evidence is not a pass. No new original-reporter migration, actual Gateway/model, Feishu API or desktop/Android visual/click acceptance is claimed; iOS and new-user trials are excluded. Four reported images do not establish a defect across every 0.22.x release.

Thanks to @mingyangtech666 for the original implementation in #458, @ywarmy for migration/configuration evidence in #459, and @mouyong for the PM/official-image evidence in #462. Preserve original commits/authors and all historical credits; report evidence is separate from code authorship.
