# v5.0.9 — Native identity, Windows installation and old PM recovery

This patch addresses [#451](https://github.com/baileyh8/hermes-feishu-streaming-card/issues/451), [#459](https://github.com/baileyh8/hermes-feishu-streaming-card/issues/459), [#462](https://github.com/baileyh8/hermes-feishu-streaming-card/issues/462) and [#463](https://github.com/baileyh8/hermes-feishu-streaming-card/issues/463). Publication and exact acceptance evidence are recorded in the [GitHub Release](https://github.com/baileyh8/hermes-feishu-streaming-card/releases/tag/v5.0.9).

- Carry native `source.user_id` separately from the Feishu mention `sender_open_id`. Reject explicit invalid/conflicting identities and retain native delivery before accepting a card when identity is unknown. Keep the original execution claim, scopes, owner, generation and epoch checks.
- Preserve raw Windows wheel bytes with binary descriptors. Use private HOME, USERPROFILE and temporary directories for official configuration children, allowing only the exact verified Git query. Recovery transactions check file/directory/reparse ownership and failure rollback.
- Recover only provable PR #458 schema-1 flat wheels: require the historical declaration, member/wheel digests, ownership and permissions, exact file URL, installed version and all package resources. Preserve workspace schema-1 and content-addressed schema-2. Similar resources or a VCS installation do not establish owned wheel provenance.
- Add fixed redacted recovery acknowledgement categories and guidance. Distinguish the new management CLI from the still-old owned runtime. Stop the actual service manager, KeepAlive and updater; retain PID/health checks, exact fence CAS and recovery evidence. See [PM recovery](wiki/pm-recovery.md).
- Integrate Dependabot #464/#465/#466 while retaining original commits/authors, audited action SHA guards and the exact Ruff pin. Concurrent confirmation tests separately verify executing and completed responses, one repair and the exact successor.

Failure reproductions, focused tests, independent QA/review, exact candidate/main/tag matrices, native Windows 3.12/3.14, ordinary noneditable wheels and public installation are separate checks. Checksums, the complete archive inventory, actual extraction metadata and anonymous downloads remain release gates; final links are recorded in Release. Pending evidence is not a pass.

No new reporter Gateway/model or real Feishu client acceptance is claimed. Desktop/Android visual/click acceptance is unverified; iOS and new-user trials are excluded. Unknown Hermes source remains refused and unknown admission identities retain native delivery. Earlier v5.0.8 field acceptance is recorded separately from the additional recovery coverage here.

Archives retain versioned roots: enter `hermes-feishu-card-v5.0.9-<platform>/` after extraction. Previous tags, assets, release notes and contributor history remain intact.
