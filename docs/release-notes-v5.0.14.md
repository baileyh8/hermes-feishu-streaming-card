# v5.0.14 — 逐轮速率关联与 Hermes 兼容

[中文](release-notes-v5.0.14.md) | [English](release-notes-v5.0.14.en.md)

本版本仍为发布候选；以下门禁未完成前不作为已发布或验收通过的声明。

## 变更范围

- #441：按原生 `(session_id, turn_id)` 精确消费速率样本，在已核验 Gateway 投影中保留原始关联，避免旧轮样本被新轮误取或同 session 多轮互相遮蔽。缺少有效关联时仍不显示速率，不改变显示阈值。报告者环境中的速率缺失尚未独立复现。
- Hermes v0.22.6：绑定精确源码 `f0d94882e89ab8d4098b5bb2f166adfb9ee0a0ab`，覆盖完成事件、producer 生命周期、投递后回调及速率关联。保留原生返回值和单次执行，不据版本字符串放行未知源码。
- v0.22.6 安装候选仅接纳可证明的 `file` 配置后端；远程或未知后端、含 `plugins.disabled_by_update` 的配置在 PM 修改前拒绝。不会清除更新保护记录，也不支持任意自定义源码。普通安装、升级和恢复仍待下述门禁。
- #482：恢复已核验的逐轮状态回调交接，保留原生 notice 路径及未知、过期归属的回退。
- #485/#486：识别精确的 Hermes `GatewayBackgroundMixin` 拆分结构，将 `gateway/run_background.py` 纳入源码归属及升级检查。不会放宽 completion 归属或未知源码保护，也不代表支持任意 Hermes main。
- #483/#484：更新 Ruff 和 mypy，改进脱敏 probe 失败信息，并要求 CI 实际执行固定后台拆分来源的测试。

## 升级与验收

旧安装须通过正常安装器刷新受管 hook，再由原服务管理方重启 Gateway。不要删除保护记录或手改 Hermes 源码。

本地运行时专项 848 项通过、13 项因未提供对应上游检出而跳过；CI 固定版本任务必须实际提供这些来源。安装器单元回归 153 项通过、2 项平台条件跳过。普通 wheel 的 v0.22.6 官方写入、成功/异常回滚、恢复与源码缓存检查共 10 项通过；实际 PM 跨代与 member 规则 2 项通过。独立 review 已通过运行时和安装准入边界。

受控真实飞书 API 已验证速率卡片创建、读回、更新、未知速率不显示和撤回。普通 writer/PM 集成使用隔离工具链 port；它们不证明真实 Gateway/model 执行。

发布仍须等待精确提交完整 CI/CodeQL、tag 门禁、公开安装及三平台发行资产核验；以发布页面的最终记录为准。此前提交的绿色 CI 不替代本候选门禁。

报告者现场、真实 Gateway/model 与客户端视觉和点击未验证。正式环境迁移另行处理；受控 API 验收不会被记作真实模型采集或客户端验收。
